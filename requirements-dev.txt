# Development / test dependencies for vector-unified (CPU-only).
#
# The shared numpy-safe building blocks live in packages/vector-core and are
# consumed in-repo via an editable install. This is the clean way to make
# `from vector_core import ...` resolve for the pipeline and for tests; a
# conftest.py path shim also resolves it with zero install for CPU-only runs.
#
#   pip install -r requirements-dev.txt
#
# NOTE: vector-core's torch extra is intentionally NOT pulled in here — the
# numpy-safe core imports without torch, and GPU-only model training is out of
# scope for CPU adoption. Install torch separately where a GPU is available.
-e ./packages/vector-core

pytest>=7.0
# Pinned exact: ruff's default rule set has changed across releases (verified
# 0.8.6 -> 0.16.2 newly flags RUF100/I001/EXE001 with zero code changes), so an
# unpinned range would make CI fail on a ruff release bump instead of a real
# regression. Bump deliberately and re-verify `ruff check` output when you do.
ruff==0.8.6
